# AiPitcher 🚀

AiPitcher is a Python-based idea pitching tool that generates startup names
and slogans from a simple business concept.

## 🚀 Features
- Startup name generation
- Creative slogan suggestions
- FastAPI backend
- Extendable AI logic

## 🛠️ Tech Stack
- Python 3
- FastAPI
- Uvicorn
- Pydantic
